# YARD ヨガ予約リマインダー

月1回のNAOクラス予約受付開始日時を管理し、指定時刻に自動でログイン〜予約まで実行するWindowsデスクトップアプリです。

## 機能

- **ログイン情報の安全な管理** — メールアドレス・パスワードはメモリ上にのみ保持し、ファイルには一切保存しません
- **予約スケジュール管理** — 追加 / 編集 / 削除 / ステータス更新
- **段階的リマインド通知**
  - 前日同時刻: 「明日17:00にNAOクラスの予約が始まります」
  - 1時間前: 「1時間後に自動予約を実行します。ログイン情報を入力してください」
  - 5分前: 確認ダイアログを表示
- **Playwright自動予約** — 受付開始時刻にChromiumを起動し、ログイン〜予約ボタンクリックまで自動実行
- **スクリーンショット保存** — 完了画面・エラー画面を `screenshots/` に保存
- **システムトレイ格納** — 最小化時はタスクバー通知領域に格納

## 動作環境

- Windows 10 / 11
- Python 3.10 以上

## インストール手順

### 1. 依存パッケージのインストール

```bash
pip install -r yard_reminder/requirements.txt
```

### 2. Playwright用Chromiumのインストール

```bash
playwright install chromium
```

## 起動方法

```bash
python yard_reminder/main.py
```

## 使い方

### ステップ1: ログイン情報を入力する

アプリ起動後、画面上部の「🔐 ログイン情報」パネルに入力します。

| 項目 | 説明 |
|------|------|
| メールアドレス | YARDアカウントのメールアドレス |
| パスワード | YARDアカウントのパスワード（●●●でマスク表示） |

「セット」ボタンを押すと「✓ 入力済み（メモリ保持中）」と表示されます。  
**入力情報はアプリ終了時に自動的に消去されます。**

### ステップ2: 予約スケジュールを登録する

「新規追加」ボタンをクリックし、以下を入力して「保存」します。

| 項目 | 例 |
|------|-----|
| クラス名 | NAO - 月曜夜ヨガ |
| スタジオ | 南流山スタジオ または おおたかの森スタジオ |
| 予約受付開始日 | 2026-06-01 |
| 時刻 | 17:00 |
| メモ | 任意 |

スタジオを選ぶと予約URLが自動的に設定されます。

| スタジオ | 予約URL |
|---------|---------|
| 南流山スタジオ | https://yard.hacomono.jp/reserve/schedule/4/10 |
| おおたかの森スタジオ | https://yard.hacomono.jp/reserve/schedule/6/16 |

### ステップ3: バックグラウンドで待機する

アプリは自動的にバックグラウンド監視スレッドを起動します。  
ウィンドウを閉じるとシステムトレイ（タスクバー右下）に格納されます。  
終了するにはトレイアイコンを右クリック →「終了」を選択してください。

### 自動予約の流れ

1. **前日同時刻** — Windows通知でリマインド
2. **1時間前** — Windows通知（ログイン情報入力を促す）
3. **5分前** — 確認ダイアログが表示される  
   → 「このまま実行」を選択すると予約をキューに登録
4. **受付開始時刻** — Chromiumを起動して自動予約実行
5. **完了** — 「予約が完了しました！」と通知 + スクリーンショット保存

### ステータスの意味

| ステータス | 意味 |
|-----------|------|
| 待機中 | 通知待ち（黒文字） |
| 通知済 | 受付開始時刻になったが手動予約 |
| 実行中 | Playwright自動予約を実行中（橙文字） |
| 予約完了 | 予約成功（グレー文字） |
| エラー | 予約失敗（赤文字） — screenshots/ を確認 |

## セキュリティについて

本アプリは以下のセキュリティ方針に従って設計されています。

### ログイン情報の取り扱い

- **ファイルへの保存は一切行いません** — `yard_schedule.json` にはスケジュール情報のみ保存します
- **コード内にハードコードしません** — メールアドレス・パスワードはアプリ実行中にユーザーが入力します
- **メモリ上にのみ保持します** — 入力されたログイン情報は実行中のプロセスメモリに保持され、アプリ終了時に自動的に破棄されます
- **パスワードはマスク表示** — パスワード入力欄は常に「●●●」で表示されます

### スクリーンショット

完了・エラー時に `screenshots/` フォルダへ保存されるスクリーンショットには、予約内容が含まれる場合があります。  
不要になった場合は手動で削除してください。

## トラブルシューティング

### 通知が届かない

Windows の通知設定で「Python」の通知が許可されているか確認してください。  
`plyer` が未インストールの場合はコンソールに通知内容が出力されます。

### 自動予約が失敗する

1. `screenshots/` フォルダ内のスクリーンショットで状況を確認してください
2. YARDサイトのログインフォームの構造が変わった可能性があります。`auto_booking.py` の CSS セレクタを確認してください
3. 満席の場合はエラー通知が表示されます

### Chromiumが起動しない

```bash
playwright install chromium
```

を再実行してください。

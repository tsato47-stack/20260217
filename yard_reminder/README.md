# YARD ヨガ予約リマインダー

YARD（hacomonoシステム）のヨガクラス予約受付開始を自動監視し、
指定時刻にログイン〜予約までを自動実行する Windows デスクトップアプリです。

---

## 動作環境

- Windows 10 / 11
- Python 3.10 以上

---

## インストール手順

### 1. リポジトリをクローン（またはダウンロード）

```
git clone <リポジトリURL>
cd yard_reminder
```

### 2. 依存パッケージをインストール

```
pip install -r requirements.txt
```

### 3. Playwright 用ブラウザをインストール

```
playwright install chromium
```

---

## 起動方法

```
python main.py
```

---

## 使い方

### ステップ 1: ログイン情報を入力

アプリ起動後、画面上部の「🔐 ログイン情報」パネルに  
YARD のメールアドレスとパスワードを入力し、「セット」ボタンを押します。

> **注意**: 入力した情報は**ファイルに保存されません**。  
> アプリを終了すると自動的に消去されます。  
> 予約実行前（遅くとも 5 分前まで）に入力してください。

### ステップ 2: 予約スケジュールを登録

「新規追加」ボタンをクリックし、以下を入力します。

| 項目 | 入力内容 |
|------|----------|
| クラス名 | 例: `NAO - 月曜夜ヨガ` |
| スタジオ | 南流山スタジオ または おおたかの森スタジオ |
| 予約受付開始日 | `YYYY-MM-DD` 形式 |
| 時刻 | `HH:MM` 形式（例: `17:00`） |
| メモ | 任意 |

### ステップ 3: 待機

登録後はアプリをそのまま起動したままにしてください（最小化可能）。  
バックグラウンドスレッドが以下のタイミングで自動動作します。

| タイミング | 動作 |
|-----------|------|
| 前日の同時刻 | Windows 通知 |
| 1 時間前 | Windows 通知 |
| 5 分前 | 確認ダイアログを表示 |
| 予約受付開始時刻 | Playwright で自動ログイン〜予約 |

### ステップ 4: 完了確認

予約完了後、`screenshots/` フォルダに完了画面のスクリーンショットが保存されます。  
一覧の「ステータス」列が「予約完了」に更新されます。

## スタジオと予約 URL

| スタジオ名 | 予約ページ |
|-----------|-----------|
| 南流山スタジオ | https://yard.hacomono.jp/reserve/schedule/4/10 |
| おおたかの森スタジオ | https://yard.hacomono.jp/reserve/schedule/6/16 |

---

## セキュリティについて

- **メールアドレス・パスワードはいかなるファイルにも保存されません。**
- アプリ起動中はメモリ上にのみ保持し、アプリ終了時に自動消去されます。
- パスワード入力欄は常に「●●●」表示（マスク）です。
- 保存されるデータは `yard_schedule.json`（予約スケジュールのみ）です。

## トラブルシューティング

| 症状 | 対処 |
|------|------|
| `playwright install chromium` でエラー | Python / pip を最新にしてから再実行 |
| 予約ボタンが見つからない | サイトの構造が変わった可能性あり。`screenshots/` 内のエラー画像を確認 |
| 通知が表示されない | `plyer` が未インストール、または Windows 通知が無効になっている |
| ログイン失敗 | メールアドレス・パスワードを再確認し「セット」を押し直す |

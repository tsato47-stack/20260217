# ヨガ予約リマインダー

月1回のヨガ教室の予約受付開始日時を管理し、リマインド通知と予約サイトの自動起動を行う Windows デスクトップアプリです。

## 機能

- 予約スケジュールの一覧管理（追加 / 編集 / 削除 / ステータス更新）
- 予約受付開始の **前日同時刻 / 1時間前 / 5分前** に Windows 通知
- 予約受付開始時刻になると **デフォルトブラウザで予約ページを自動起動**
- 最小化時はシステムトレイに格納
- データは `yoga_reminder/yoga_schedule.json` にローカル保存

## 動作環境

- Windows 10 / 11
- Python 3.10 以上

## インストール

```bash
pip install -r requirements.txt
```

## 起動方法

```bash
python yoga_reminder/main.py
```

## 使い方

### スケジュール登録

1. **「新規追加」** ボタンをクリック
2. 以下の項目を入力して **「保存」**
   | 項目 | 例 |
   |------|-----|
   | クラス名 | 月曜夜ヨガ |
   | 予約受付開始日 | 2026-05-01 |
   | 時刻 | 10:00 |
   | 予約ページURL | https://example.com/yoga |
   | メモ | 任意 |

### ステータス管理

一覧でスケジュールを選択し **「ステータス更新」** から変更できます。

| ステータス | 意味 |
|-----------|------|
| 待機中 | 通知待ち（黒文字） |
| 通知済 | ブラウザ起動済み（青文字） |
| 予約完了 | 予約が完了した（グレー文字） |

### システムトレイへの格納

ウィンドウを閉じるとシステムトレイに格納されます。  
タスクバーの通知領域のアイコンをダブルクリックするとウィンドウが再表示されます。  
終了する場合はアイコンを右クリック → **「終了」** を選択してください。

> **Note:** `pystray` および `Pillow` がインストールされていない場合は、ウィンドウを閉じるとアプリが終了します。

## ファイル構成

```
yoga_reminder/
├── main.py             # エントリーポイント
├── gui.py              # tkinter GUI
├── scheduler.py        # 通知・スケジュール管理
├── data_manager.py     # JSON 読み書き
└── yoga_schedule.json  # データファイル（自動生成）
requirements.txt
README.md
```

## 通知が届かない場合

- Windows の通知設定で「Python」または「plyer」の通知が許可されているか確認してください。
- `plyer` が未インストールの場合はコンソールに通知内容が出力されます。
